# 以影像辨識技術實作半導體晶圓篩選系統之研究
> **國立虎尾科技大學 資訊工程系 實務專題（二）製作報告**
> **指導教授：黃建宏 教授**
> **專組組員：范芷紜（41243104）、郭俞汎（41043104）**



本研究旨在建立一套以深度學習為基礎之自動化晶圓篩選與缺陷分類流程。針對 WM811K 晶圓圖資料集中嚴重的類別不平衡問題（無缺陷類別 None 佔整體 85.24%），專案採用 **Two-stage分類流程**，並結合 **greedy-based 方法**進行資料增強策略搜尋與**集成學習**多數決投票，成功將整體模型分類之平均 F1 分數提升至 **0.89**。

---

## 🎯 研究核心方法 (Research Methods)

依據專題報告內容，系統之核心架構與處理策略如下：

1. **Two-Stage 分類流程**：
   - **第一階段 (Stage 1)**：進行 None 與 Defect 二元分類，判斷晶圓是否具有缺陷，過濾高比例的無缺陷樣本，降低模型受 None 類別的影響。
   - **第二階段 (Stage 2)**：專注於缺陷樣本之間的八類缺陷分類（Center, Donut, Edge-loc, Edge-ring, Loc, Random, Scratch, Near-Full）。
2. **啟發式資料增強策略 (greedy-based 方法)**：
   - 在單一模型訓練階段，依據驗證集表現逐步選擇較適合的資料增強組合，最終 VGG11-BN 選取之組合為 **Sharpen** 與 **Noise**；DenseNet121 選取 **Erosion**；Swin Transformer 選取 **Dilation + Sharpen**。
3. **模型結構微調**：
   - 針對 **DenseNet121** 初始特徵擷取層進行微調。將第一層卷積由原始 7×7 (stride=2) 調整為 **3×3 (stride=1)**；並將初始 pooling layer 移除，**以 Identity 取代**。此調整目的在於減少初始階段的影像壓縮，保留更多 64×64 晶圓影像之低階細節特徵。
4. **類別不平衡處理策略**：
   - 採用各類別樣本數比例之倒數作為權重計算方式，並將權重加入損失函數中。

## 📊 實驗結果與數據分析 (Experimental Results)

本研究評估並比較了 VGG11-BN、DenseNet121 與 Swin Transformer 三種單一模型，並將最佳結果導入集成學習架構：

| 模型 / 架構方法 | 主要超參數變因設定 | 最佳平均 F1 分數 | 實驗核心結論與特點 |
| :--- | :--- | :---: | :--- |
| **VGG11-BN** | Batch Size = 64 | **0.83** | 具備最佳推論時間（Two-stage 總時間為 91.96 秒）。 |
| **DenseNet121** | Loss Weight Strength = 0.5 | **0.82** | 適度縮小類別權重差異，能於多數與少數類別間取得較穩定分類效果。 |
| **Swin Transformer** | Learning Rate = 5e-5 | **0.82** | 載入 ImageNet 預訓練權重，輸入前將影像 resize 至 224×224 進行微調。 |
| 🏆 **集成學習** | **三模型多數決投票** | ⭐ **0.89** | **經 greedy-based 方法整合，多模型間具互補性，顯著提升整體分類效果。** |

### 💡 較差類別子集之改善分析
針對 VGG11-BN 分類表現相對較差的 **Loc（局部區域缺陷）** 與 **Scratch（線狀或刮痕分布）** 進行測試子集評估：
- **Loc 缺陷**：F1-score 從單一模型的 0.86 經由 greedy Stage 2 集成模型後提升至 **0.91**。
- **Scratch 缺陷**：F1-score 從單一模型的 0.76 經由 greedy Stage 2 集成模型後提升至 **0.90**。
- **結論**：集成學習能整合不同架構對缺陷特徵的判斷結果，有效補足單一模型在特定困難類別上的不足。
